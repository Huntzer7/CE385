    ***if ห้ามใช้ var · ห้ามใช้ + ต่อข้อความ ให้ใช้ Template Literal เท่านั้น · มี comment อย่างน้อย 2 บรรทัด · "ปีที่จะจบ" ต้องคำนวณจากตัวแปร ไม่ใช่พิมพ์เลขตายตัว***

ในส่วนของ ***const*** จะมีตัวเลขที่ใส่ (" ")
-เกณฑ์การเลือกใส่ก็คือตัวเลขที่เป็นเชิงปริมาณและต้องนำไปคำนวณหรือนับจะไม่ใส่
-ตัวเลขที่ไม่ได้นำไปบวกลบคูณหารจะใส่
ในส่วนของ ***function*** 
-ต้องสร้างตัวแปรคำนวณปีที่เหลือจากหลักสูตร4ปีเพื่อให้ได้ตัวเลขปีที่จะจบที่เหลือไปบวกกับปี 2569 ก็จะได้ปีที่จะจบ
-ที่ต้องใส่ let เพราะว่ากันตัวแปรหลุดนอกฟังก์ชัน,กันโดนเขียนทับเผื่อไฟล์อื่นใช้ชื่อตัวแปรเหมือนกัน
-ใส่ return เพราะให้ฟังก์ชันส่งค่า ปีที่จะจบ ออกมาแทนจุดที่เรียกใช้ เพราะถ้าไม่มีผลลัพธ์ก็จะเป็น undefined แทน
