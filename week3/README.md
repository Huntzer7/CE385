# ex3-transform
**ส่วนที่ 1**
-**getNames** ใช้ ".map()" เพื่อคืน ชื่อ ที่แปลงรูปแล้ว ของทุกคน

-**getPassedStudents** ใช้ ".filter()" เขียนคล้าย "hasFallingStudent" ในข้อสอง แต่เปลี่ยนเป็นคนที่คะแนนผ่านมากกว่าหรือเท่ากับ 50 แทน แล้วคืนค่าเป็น array ของ object ที่ผ่าน 

-**getTotalScore** ใช้ ".reduce()" โดย "sum" คือ ผลบวกสะสม และ "s" คือ คะแนนของที่จะเช็คต่อไป บวกสะสมกับ sum มาเรื่อยๆจนครบ และ 0 คือค่าเรื่มต้นของ "sum" ถ้าไม่มี 0 โค้ดจะ "error" 

-**getAverageScore** ใช้ "if (students.length === 0) return 0" เช็คว่ามี "student" มั้ย ถ้าไม่มีให้ return 0 ออกไปแทนและจบการทำงาน function มี "return 0" เพื่อไม่ให้ "return NaN" ออกมา

-**toGrade** เอาฟังก์ชัน "toGrade" มาจากข้อที่หนึ่งก่อน โดย "GRADE.find(g => score >= g.min)?.grade ?? "F";" คือ ให้ไล่ค้นหาใน array Grade ว่าคะแนนมากกว่าหรือเท่ากับคะแนนใน array Grade มั้ยถ้าไม่มีให้คืนค่า grade เป็น "คะแนนไม่อยู่ระหว่างเลข 0-100" ได้เลย 

-**countByGrade**  ตัวแปร "acc" = accumulator คือตัวสะสม ซึ่งในตอนแรกจะมีค่าเท่ากับค่าว่าง "{}". 

-"const grade = toGrade(s.score);" คือแปลงคะแนนเป็นเกรด โดย "s" = students. 

-"acc[grade] = (acc[grade] ?? 0) + 1;" ในบรรทัดนี้ ถ้าในตอนแรก "acc" ยังไม่เคยเจอเกรดไหนเลย ค่าของ "acc"ในตอนแรกจึงจะเป็น "Undefined" ตัว "??" จะเข้ามาช่วยทำงานโดยจะคืนค่า "0" ออกไปทันที จากนั้นจะเอาไปบวกกับ 1 ผลลัพธ์ในตอนแรกก็จะกลายเป็น 1 จากนั้นถ้า "acc" เจอเกรดเดิมอีกเป็นครั้งที่สอง ก็จะนำเลข 1 นั้นไปบวกกับ 1 อีกที ยอดนั้นก็จะกลายเป็น 2  

-"return acc;" ทุกครั้งที่นับคะแนนของนักเรียนคนนั้นเสร็จแล้ว จำเป็นต้อง return ค่าทุกรอบเพื่อส่งยอดที่อัปเดตล่าสุดแล้วไปรันโปรแกรมนับนักเรียนคนต่อไป

-**getTopStudent** "if (students.length === 0) return null;" เช็คค่า array ว่า มีค่าเท่ากับ 0 มั้ย ถ้ามีให้คืนค่าเป็น "null" ถ้าไม่ ให้คืนค่า "return students.reduce((best, s) => s.score > best.score ? s : best );" best คือคนที่คะแนนดีที่สุดตอนไล่เช็ค array ส่วน s คือ score ของที่กำลังเช็คกับคะแนน best ในตอนนั้นๆ โดย "?" เข้ามาทำงานแบบนี้ คะแนนของคนที่เช็คในตอนนั้น "(score)" มากกว่าคะแนนของคนที่มากที่สุดมั้ย "(best)" ถ้าจริงให้คืนค่า "s"(score) แทนค่าของ "best" 

**ส่วนที่ 2**
-**avgCEPassed** การต่อท่อคำสั่ง โดยเริ่มจากการกรอง "(filter)" เฉพาะคนที่อยู่ในสาขา "CE" เท่านั้นมาก่อน แล้วกรองคนที่คะแนนมากว่า 50 "filter student score > 50" มาเพราะที่มีคะแนนมากกว่า 50 คือคนที่ผ่าน จากนั้น ".map()" เอาแค่คะแนนเท่านั้น เพราะก่อนหน้านั้นข้อมูลจะเป็น "object" ตัวเต็ม มีทั้งชื่อ สาขา คะแนน อีเมล แต่โจทย์ต้องการแค่คะแนนเฉลี่ยเท่านั้น จากนั้นใช้ ".reduce((sum,score,_,arr) => sum + score / arr.length,0);" โดยตัว "_" เป็นตัวแทนของ "Index" เพื่อบ่งบอกว่าไม่สนใจตัวนี้ เป็น convention และ "sum" เริ่มต้นที่ 0 ที่ระบุไว้ท้ายคำสั่งนี้
