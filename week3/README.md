**ส่วนที่ 1**
-**isValidscore** ได้ทำการใช้ Arrow function และเพิ่มเงื่อนไข1ข้อคือ ตรวจสอบว่าค่าที่รับเข้ามาคือตัวเลขไม่ใช่ string

-**calculateWorkshopScore** **calculateTotal** เขียนเป็น function ปกติเพราะ ถ้าใช้ Arrow function โค้ดจะยาวเกินไป
